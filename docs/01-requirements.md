# 01 要件

## プロダクトの約束

ユーザーが安全な場所で立ち止まり、選んだ星へ iPhone を向ける。方向が近づくほど案内の曖昧さがほどけ、方向が合った瞬間に、その星だけの音・触覚・形で発見を伝える。

## 必須要件

- 赤経・赤緯、端末内時計、現在地から方位角・高度を端末内計算する。
- `CLLocationManager` の真北方位と `CMDeviceMotion` の姿勢から端末が向く空の方向を求める。
- 標準探索はカメラを使わない。カメラ重畳は後続フェーズの補助機能とする。
- 星が地平線下なら通常探索を始めず、練習モードだけを提示する。
- 昼・曇天でも練習できる。練習完了は「発見」ではなく「方向が合いました」と表現する。
- 「聴く」「触れる」「見る」を同じ階層・面積で提示し、どの一つだけでも完了できる。
- 主要フローに縦スクロールを使わない。
- 探索前に毎回、安全確認を一操作で行う。
- 歩行、走行、自動車移動を検知したらガイドと発見判定を停止する。
- 方位精度を数値と平易な状態名で表示する。精度不良中は発見判定をしない。
- 8 の字補正と、車内・磁石・鉄骨建物付近で誤差が増える旨を案内する。
- 日本語・英語、VoiceOver、Dynamic Type、Reduce Motion、Reduce Transparency に対応する。
- 通信、アカウント、広告、外部解析 SDK を使用しない。
- 位置情報は「使用中のみ」とし、計算結果を含め外部送信しない。
- 星データ、星座線、音、触覚、アイコン、視覚素材は利用条件を記録したもの、または完全オリジナルだけを使う。

## Phase 1 の範囲

### 含む

- 北極星、シリウス、ベガ、ベテルギウス、リゲル
- 固定観測時の星方向計算
- 3 種類の案内モード
- 練習センサー値による屋内デモ
- 実機検証用の精度・方位・高度・誤差表示
- 発見の安定時間判定

### 含まない

- 全天恒星カタログ
- カメラ画像上の星認識
- ARKit 依存の必須フロー
- ソーシャル共有、クラウド同期、ユーザー追跡
- Apple から求められていない審査動画

## 成功指標

- 晴天の屋外・磁気干渉の少ない場所で、対象星 5 個のうち観測可能な星へ案内できる。
- 3 モードすべてで、初見ユーザーが星選択から方向一致まで完了できる。
- 精度が悪い環境では誤った「発見」を出さず、原因と次の行動を説明できる。
- 暗所の実機輝度 5–20% で操作と状態を判別でき、発見演出が眩しくない。
