# 全天の星図と選択案内 — 2026-10-24

## 体験

- 入口を「夜空をひらく」にし、現時刻/現在地の地平線上の星と星座線を表示。従来5星の直接探索も残す。
- 88星座（へび座の2領域を1星座へ統合）と肉眼で見える明るさを中心とした多数の恒星を収録。夜空にない星座を全部同時に表示する意味ではない。
- 点をタップして恒星、星座名をタップして星座を選択。選択内容を示し、明示的な「音と振動で案内」で探索開始。星座の目標は地平線上5度以上の最も明るい構成星とし、目印の星名を併記。
- VoiceOverや細かい点を押しにくい場合は星座一覧から同じ選択ができる。地平線下の対象は案内開始不可。
- 端末を対象方向へ向けるほど既存のガイド間隔が短くなる。星図を眺めている間は音/振動を鳴らさない。音/振動/画面の既存選択と停止/戻るを維持。
- カメラは任意、星の画像認識ではない。Reduce Motionでは静止星図、手動更新、カメラ停止を維持。

## データと境界

- 恒星位置はYale BSC5のMITライセンスJSON輸出（Bretton Wade）を候補にし、J2000座標/等級を抽出。恒星の実座標と星座線は別資産として出典を記録。Hipparcos/Tychoの恒星表、Stellariumの画像/実装は取り込まない。
- 星座線はd3-celestialのBSD-3-Clause配布データ（IAU由来と作者の修正）を候補にし、端点をYaleの近傍恒星に照合して線を作る。誤対応を距離上限で拒否し、未照合を黙って架空星にしない。
- 既存31星のID/出典/固有運動は維持して同じ恒星を二重表示しない。新規恒星の固有運動0近似は明示。精密測定用途ではない。
- 収録数、全88星座の端点/線、出典版/取得日/ハッシュを検証。MIT/BSD全文とIAU由来の注記を同梱し、既存の商用権利/署名/実機ゲートは維持する。
- 方角精度<=25度で粗い案内、<=10度で発見、方位<=2秒、姿勢<=0.25秒、移動/位置/磁気/重力の安全判定は変更しない。垂直時警告は原因未確定であり、本拡張で解決したとは言わない。
- 全天の位置計算は最大毎秒1回、姿勢投影は既存の更新頻度。星名は間引き、選択星と星座名を優先。全星へのラベル付けで画面を埋めない。

## 方針

少数星への手動追記は88星座を覆えず更新不能、外部星図SDKは通信/課金/ライセンスと既存音ガイドの統合負担を増やすため、既存Swiftの計算/投影にローカルデータを追加する。今ある配色・夜間表示を維持し、新しい映像演出は追加しない。
