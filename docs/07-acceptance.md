# 07 受入条件

## 体験

- [ ] 星選択から探索まで、毎回の安全確認を除いて 2 操作以内。
- [ ] 「聴く」「触れる」「見る」の各モードだけで選択、探索、完了まで進める。
- [ ] 地平線下、練習、精度不良、移動中が見た目と読み上げで区別できる。
- [ ] 発見時の音・触覚・形が対象星ごとに識別できる。
- [ ] 主要画面に縦スクロールがない。

## 計算とセンサー

- [ ] [天体計算・センサー検証](ASTRONOMY-VALIDATION.md)の同一式回帰値を指定許容差内で再現し、独立SOFA比較はv0で方向角距離0.6°以内、本番候補で0.1°以内。
- [ ] 方位角の 0° / 360° 境界で方向差が飛ばない。
- [ ] 幾何高度 < 0° は自動で練習へ切り替わり、0°以上5°未満では低高度警告が出る。
- [ ] ライブ発見は幾何高度 2°以上だけ。0°以上2°未満はライブ案内を出せても発見しない。
- [ ] 有効方位精度の境界が `good <= 8°`、`fair > 8°かつ<=10°`、`needsCalibration >10°かつ<=25°`、`unavailable = 無効値または>25°` と一致する。
- [ ] good/fair は発見可能、needsCalibration は粗い案内だけ、unavailable は音・触覚・画面方向案内と発見判定をすべて停止する。
- [ ] 発見許容角が `clamp(3 + 有効方位精度/3, 3, 6)` 度になり、その角内で 0.8 秒以上連続した時だけ一度発見する。
- [ ] 歩行、走行、自転車、自動車移動中は全案内と発見判定を停止する。
- [ ] センサー更新が途絶えた場合に、古い方向で案内を続けない。

## アクセシビリティと暗所

- [ ] VoiceOver だけで全フローを完了できる。
- [ ] センサー更新のたびに読み上げず、方向帯の変化時だけ通知する。
- [ ] Reduce Motion で意味が欠落しない。
- [ ] Reduce Transparency で文字コントラストが落ちない。
- [ ] 375 × 667 pt、430 × 932 pt、最大 Dynamic Type で操作不能にならない。
- [ ] 実機輝度 5–20% で文字と操作を識別でき、発見時に眩しい面発光がない。

## プライバシーと権利

- [ ] 起動から探索までネットワーク通信が発生しない。
- [ ] 位置・モーション・探索履歴を端末外へ送らない。
- [ ] 位置権限は「使用中のみ」で、拒否時は練習モードを利用できる。
- [ ] 外部解析、広告、ログイン SDK が含まれない。
- [ ] [MVP 要件とデータ権利判断](REQUIREMENTS-AND-RIGHTS.md)の台帳に、全データと素材の出典、取得日、ライセンス、加工内容、根拠保存先、確認者が記録されている。
- [ ] 出荷対象の各星データ・固有名・素材は `commercial_status = yes` または対象範囲を含む書面許諾で確定し、`conditional`、不明、非商用限定の行が 0 件である。
- [ ] Hipparcos/Tycho の CC BY-NC データを、別途商用許諾なしに配布バイナリへ含めていない。IAU 固有名を使う場合は必要な CC BY 4.0 表示を含める。
- [ ] 他社の星図画像、星座線、音源、触覚パターンを流用していない。
- [ ] 星座線は権利確認済み星 ID から独自に設計し、作者・作成日・設計根拠・変更履歴がある。

## リリースゲート

1. 数学単体テスト。
2. シミュレーター UI / VoiceOver / Dynamic Type 検証。
3. Xcode の開発署名による実機ビルドで、[屋外実機テスト](08-field-test.md)を完了する。
4. 車内、磁石、鉄骨建物付近で誤差と警告を確認し、方位品質別の停止動作を確認する。
5. [MVP 要件とデータ権利判断](REQUIREMENTS-AND-RIGHTS.md)のリリースブロッカーを 0 件にする。
6. 1〜5 の通過後にだけ Codemagic 設定と署名付き Release archive/IPA を作る。
7. 実在する IPA とチェックサムを用い、Sideloadly で指定実機へ導入して権限・音・触覚・センサーを再確認する。
8. App Store Connect のプライバシー回答、メタデータ、スクリーンショットを最終 IPA と照合する。
9. Apple から明示的に要求された場合だけ審査動画を作成する。

現時点は 3 より前であり、Codemagic 設定、署名付き IPA、ダウンロードリンクは存在しない。権利が未確定のデータを含むビルドは、テスト用途を越えて外部配布しない。
