# 02 画面遷移

```text
初回説明
   ↓
星を選ぶ ── 高度 < 0° ──→ 自動で練習へ切替
   ↓ 高度 >= 0°（0°以上5°未満は低高度警告）
安全確認（毎回）
   ↓
方位確認（good / fair / needsCalibration / unavailable）
   ↓
探す ←──────── モード切替：聴く / 触れる / 見る
   ├─ 歩行・走行・車移動 → 一時停止 → 立ち止まると再開
   ├─ needsCalibration → 粗い案内だけ + 補正案内
   ├─ unavailable → 全案内停止 + 補正/練習案内
   ├─ 高度 0°以上2°未満 → ライブ案内のみ（発見不可）
   └─ good/fair・高度 >= 2°・適応許容角内で 0.8 秒 → 発見 / 練習一致
                              ├─ 次の星
                              └─ 星座をたどる（後続フェーズ）
```

## 画面ごとの責務

### 星を選ぶ

- 最大 4 枚を 2 × 2 で見せる。小さい画面や最大 Dynamic Type では横ページングへ切り替える。
- 固有名、観測可否、方位、高度だけを表示する。
- 幾何高度が 0°未満なら選択後に自動で練習へ切り替える。0°以上5°未満は「低い空・見え方に不確かさあり」と表示する。
- 3 モードは下部に同じ大きさで常設する。

### 安全確認

- 「立ち止まって空を見上げます」「足元、車、自転車、人を確認してください」を簡潔に表示する。
- 主操作は「立ち止まって開始」一つ。

### 方位補正

- 有効方位精度は `good: 0〜8°`、`fair: 8°超〜10°`、`needsCalibration: 10°超〜25°`、`unavailable: 無効値または25°超` の境界で表示する。
- good/fair は発見判定に進める。needsCalibration は粗い方向案内だけを残して補正を促し、unavailable は音・触覚・画面方向案内をすべて止める。
- 数値と「良好 / 使用可 / 調整が必要 / 利用不可」を併記する。補正をスキップしても品質ゲートは緩めない。
- Reduce Motion 時は静止した 3 段階図、それ以外は低速の細線アニメーションを使う。

### 探す

- 中央 70% を「聴覚レンズ」に割り当てる。
- 上部は戻る、星名、精度だけ。下部は 3 モード。
- 装飾 Canvas と、VoiceOver が読む状態テキストを分離する。
- センサー値は連続更新しても、読み上げは方向帯が変わった時だけ、最低 2 秒間隔にする。
- 発見許容角 `T` は有効方位精度に応じた 3〜6°（`T = clamp(3 + 精度/3, 3, 6)`）とし、good/fair かつ `角距離 <= T` が途切れず 0.8 秒続いた場合だけ一度発見する。
- ライブ発見には幾何高度 2°以上が必要。0°以上5°未満は低高度警告を残し、うち 0°以上2°未満では発見させない。

### 発見

- 面発光や白フラッシュは使わず、細い輪を一度だけ広げる。
- 通常は「見つけました」、練習は「方向が合いました」。
- 「次の星」「星座をたどる」だけを提示する。
